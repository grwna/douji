# Character Mapping Data
This document contains documentation for how the character mappings are created. 

## Character Mappings
There are currently 2 character mappings:
1. Jp-Zh simplified-Zh traditional
2. Zh simplified-Zh traditional 

The usage of different mappings is to facilitate lookups of characters that might not exist in some character sets. In v1.0.0, if you are looking up a character in simplified chinese, it might not exist in the Japanese character sets, causing a 'character not found' popup. This means you cannot use this extension to simply view the simplified to traditional mappings if the character does not exist in the Japanese character set.
